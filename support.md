# 一本清单（OneList）技术支持

如果您在使用一本清单时遇到问题，请先检查：

1. **通知没有按时出现：**请在系统“设置 → 通知”中允许一本清单发送通知，并确认事项已设置提醒时间；
2. **系统日历或提醒事项没有显示：**请在系统“设置 → 隐私与安全性”中允许一本清单访问日历或提醒事项；
3. **Apple Watch 或小组件没有及时更新：**请保持 iPhone 与 Apple Watch 正常连接，并打开一次 iPhone 上的一本清单以刷新数据；
4. **需要备份或恢复事项：**请使用应用设置中的本地备份功能，并妥善保存导出的备份文件。

如问题仍未解决，请将问题现象、设备型号、系统版本和复现步骤发送至：

[onebooksoftware@outlook.com](mailto:onebooksoftware@outlook.com)

请不要在邮件中发送密码、验证码或其他敏感信息。

# OneList Support

If you encounter a problem while using OneList, please check the following:

1. **Notifications do not arrive on time:** Allow OneList to send notifications in **Settings → Notifications**, and make sure the task has a reminder time;
2. **Apple Calendar or Reminders content is missing:** Allow OneList to access Calendar or Reminders in **Settings → Privacy & Security**;
3. **Apple Watch or widgets are not updating:** Keep the iPhone and Apple Watch connected, then open OneList once on the iPhone to refresh the data;
4. **You need to back up or restore tasks:** Use the local backup feature in the app settings and keep the exported backup file in a safe location.

If the issue continues, email the problem description, device model, system version, and reproduction steps to:

[onebooksoftware@outlook.com](mailto:onebooksoftware@outlook.com)

Do not include passwords, verification codes, or other sensitive information in the email.
